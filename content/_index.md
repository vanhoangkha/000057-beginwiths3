# STARTING WITH AMAZON S3

{{% notice tip %}}
**Modern Alternative:** AWS now recommends using [AWS Amplify Hosting](https://aws.amazon.com/amplify/hosting/) for static website hosting as it provides better security, HTTPS by default, and global CDN without manual CloudFront configuration. This tutorial teaches S3 fundamentals which are still valuable for understanding AWS storage concepts.
{{% /notice %}}

Amazon Simple Storage Service (Amazon S3) is an object storage service that provides on-demand scalability, ensuring high levels of data availability, security, and performance.

S3 is built to meet the needs of customers of all sizes and industries who can use this service to store and protect any amount of data.

S3 can be used for many use cases such as data warehouse, websites, mobile apps, backup and restore, storage, enterprise applications, IoT devices, and data analytics. In addition, Amazon S3 provides easy-to-use management features, so you can organize your data and configure access controls to meet the specific requirements of your business, organization, and compliance requirements.

Amazon S3 is designed for 99.999999999% (11 9's) durability and stores the data of millions of applications for companies worldwide.
