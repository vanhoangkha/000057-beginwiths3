#### Clean up resources

#### Empty S3 bucket

1. Go to **[AWS S3](https://console.aws.amazon.com/s3/)**
2. In the **Bucket name** list, select the bucket related to the lab.
3. Select **Empty**
4. In the **Empty bucket** page, confirm and select **Empty**

#### Delete S3 Bucket

1. Go to **[AWS S3](https://console.aws.amazon.com/s3/)**
2. Select **S3 bucket** related to the lab.
3. Select **Delete bucket**

#### Delete Cloudfont

1. Go to **[Amazon CloudFront](https://console.aws.amazon.com/cloudfront/)**
2. Check the box before Distributions ID, in the upper right corner - select **Disable**, this will take a few minutes.
3. After Disable is complete, select **Delete**
