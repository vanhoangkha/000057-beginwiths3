#### Download data

We perform data upload (source code) to S3 bucket storage.

We download **[Source code](https://github.com/AWS-First-Cloud-Journey/S3-Website/archive/refs/heads/main.zip)** to the device.

1. In the interface **S3 bucket** just created.

   - Currently, we see no **object**.
   - Select **Upload** to download data (source code downloaded and unzipped)

![Upload data](/images/2.2-Uploaddata/0001.png?featherlight=false&width=90pc)

2. In the **Upload** interface

- Turn on the window containing the **folder**, **file** downloaded and unzipped in the above step
- Press the key combination **Ctrl A** to select all **folders**, **files** in the **S3-Website-main** folder
- Drag all selected **folders**, **files** and drop them into **upload** section of **S3 Bucket**

![Upload data](/images/2.2-Uploaddata/0002'.png?featherlight=false&width=90pc)

- Results after dropping the **folder**, **file** into **S3 Bucket**

![Upload data](/images/2.2-Uploaddata/0002''.png?featherlight=false&width=90pc)

3. Select **Upload**

![Upload data](/images/2.2-Uploaddata/0002'''.png?featherlight=false&width=90pc)

4. Wait for 5 minutes, and finish uploading data.

![Upload data](/images/2.2-Uploaddata/0004.png?featherlight=false&width=90pc)

5. Observe the uploaded folder.

![Upload data](/images/2.2-Uploaddata/0005'.png?featherlight=false&width=90pc)
